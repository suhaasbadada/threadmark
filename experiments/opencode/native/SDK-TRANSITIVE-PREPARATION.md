## What is prepared

`sdk_compiler_candidate.py` accepts explicit identities, individual file hashes
and already-owned archive **bytes**. It rechecks compressed SHA-256/SHA-512,
strict archive structure, actual package name/version and complete metadata.
All declarations, nested package metadata and actual notice files must be bound.
It preserves original nested npm paths and versions; it does not hoist, install,
invent aliases, resolve imports or run package scripts. Selected implementation
TS/TSX must be an actual literal export/type target and receive `typing_source`,
not JS-execution status. This candidate selects no implementation sources.

The private exact input plan and candidate bind **22 packages, 1,464 declarations,
1,512 potential reads including fixtures, 9 nested metadata files and 15 archive
notices**. All 737 implementation-type sources remain excluded (including the
prior 11 web-tree-sitter files). Every potential read has its own relative path
and hash; not every potential read must be consumed. Private candidate data also
retains complete original metadata/notices, reference facts, and exact fixture
API declaration-file bindings. Public `sdk-transitive-discovery.json` records
counts, the thirteen-package delta, notice hashes and whole-selection digest
bindings; the unchanged earlier JSON retains the original nine inventories.

The package delta comes from actual declaration import syntax: protocol/schema/
ai/util/effect, provider -> JSON Schema, Solid -> csstype, OpenTUI -> marked and
bun-ffi-structs, Node/ws and undici-types, plus standard-schema. Lexical import,
import-type and import-equals facts are **selection proposals only**, never a
TypeScript resolver. Documentation examples/string-literal values are not scanned
as imports. Package exports/imports, conditional and wildcard targets, reference
directives, ambient effects and unsupported syntax still need review and later
official compiler observation. Zero unknown operands in recognized syntax does
not mean all syntax or semantic dependencies are understood.

Concrete remaining review obligations include optional `bun`, `electron`, `vite`,
`google-auth-library` references, and util's actual `#runtime-import` conditional
mapping. Their occurrence in potential reads does not establish consumption by
the chosen entrypoints. Standard-schema's custom `source` export points at
`./src/index.ts`, absent from the actual archive/selection; its conditional

ambient types, or silently drop product scope. There are 265 reference directives

`project_types` does not support this combined nested metadata/notice contract.
It was **not changed or bypassed**. No physical package projection is offered by
