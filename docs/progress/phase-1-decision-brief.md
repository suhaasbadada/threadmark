## Limitations

An explicit exact marker protocol is not Markdown semantics, logical
contradiction detection or independent source authority. Snapshot labels/hashes
prove caller-supplied byte consistency only, not authentication, Git identity,
permissions or live freshness. A malicious current marker stays a quoted value,
never becomes an instruction. Earlier stdout previews remain visible after
cancel, but final canceled output contains only the preserved original and no
evidence. No runtime, certified host, useful-task, adoption or phase-completion
claim follows from passing these synthetic tests.
